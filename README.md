# Driver planner (temporary public copy)

The Glasgow Children's Hospital Charity driver planner, built at the JPMorgan Chase Data for Good hackathon,
Glasgow, October 2026 (Team 29). Open it at **https://levroz630.github.io/gchc-driver-planner/**.

It runs entirely in your web browser: the spreadsheets you add are read on your own computer and never uploaded.
This repo holds only the page, its code and public open data (Open Government Licence); no charity data. The
project itself is at https://github.com/glasgow26/Team-29. This copy is temporary.
